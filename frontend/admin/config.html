LyricBridge

Web renderer

Loads the enhanced lyrics interface in Jellyfin-hosted web clients. Uses File Transformation when available, otherwise updates a writable web index. Reload browser clients after changes.

Storage and retrieval

Restart required: the active storage directory stays unchanged until restart.
Changing storage

Choose a writable absolute path. Music files remain read-only. Restart after changing storage. Back up existing data first; unsupported preview databases require a new empty directory and are never migrated automatically.

Check sample tracks before enabling. Instrumental tracks are skipped.
Advanced maintenance

Reset removes all LyricBridge-managed original lyrics, raw responses, saved versions, translations, pronunciation, timing corrections, classifications, and request history. Settings, credentials, and user display preferences and song language overrides are kept. Music files, source-library lyrics, and other plugins are untouched. Lyrics can be retrieved again when opened.
